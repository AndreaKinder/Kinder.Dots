# Dotly Dotfiles Configuration Skill (Index)

Lightweight index for configuring and maintaining `$HOME/.dotfiles` managed with [CodelyTV/dotly](https://github.com/CodelyTV/dotly).
**To save context, read only the specific reference file(s) from `references/` that match your current task.**

## Core Rules (Always Apply)

1. **NEVER hardcode user-specific absolute paths** (e.g., `/home/<user>/...` or `/Users/<user>/...`) in any script, shell file, symlink YAML, config, or doc inside `$DOTFILES_PATH`.
   - Always use portable environment variables (`$HOME`, `$DOTFILES_PATH`, `$DOTLY_PATH`, `$ZIM_HOME`, `$XDG_CONFIG_HOME`, etc.) or `~` (in Dotbot `symlinks/*.yaml`).
   - Externalize machine-specific paths, secrets, or local overrides via environment variables loaded from an untracked `.env` file or exported in `shell/exports.sh` using `$HOME` / `$DOTFILES_PATH`.
2. **Never edit `modules/dotly/` or `shell/zsh/.zim/` directly**:
   - `modules/dotly/` is the upstream Git submodule (`$DOTLY_PATH`).
   - `shell/zsh/.zim/` is auto-generated by `zimfw` (`$ZIM_HOME`) and gitignored.
